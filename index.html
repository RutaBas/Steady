Backup

Your entries are saved only on this device. Nobody else can see them. But iOS can clear a web app's data, for example if you don't open it for a few weeks or your phone runs low on space. Export a backup regularly and keep it in Files, iCloud Drive or your notes.

Backup as text (fallback)

If file export doesn't work, copy the backup as text and paste it into your notes app. To restore, paste it back here. The text backup doesn't include your Joy jar (photos are too big to paste), so use Export backup file for that.

Reminders & sleep

Set up a gentle evening reminder

Steady doesn't send notifications itself, so nothing leaves your phone. iOS Shortcuts can nudge you instead.

  1. Open the Shortcuts app → Automation tab → + (or New Automation).
  2. Choose Time of Day, pick a time such as 8:00 pm, set Repeat: Daily, and choose Run Immediately.
  3. Tap New Blank Automation. Add Run Shortcut → Steady sleep (set up below), or just add Show Notification with text such as How's your mood today?.
  4. When the nudge arrives, open Steady from your Home Screen.
Fill sleep from Apple Health or Oura

Web apps can't read Apple Health directly. A small Shortcut reads last night's sleep and copies it, then Fill from Health pastes it in. Using Oura? Turn on Oura app → Settings → Apple Health so your Oura sleep lands in Health.

  1. In Shortcuts, tap + and name the shortcut Steady sleep.
  2. Add Find Health Samples: Type Sleep (Sleep Analysis). Add filters End Date is in the last 1 day, and Value is not In Bed and Value is not Awake.
  3. Add Get Details of Health Samples → Duration.
  4. Add Calculate Statistics → Sum. Then add Calculate → Statistics Result ÷ 3600 (turns seconds into hours). Then add Round Number → Tenths.
  5. Add Format Date → Current Date, Custom format yyyy-MM-dd.
  6. Add Text: steady-sleep: Formatted Date : Rounded Number, with no spaces. It should look like steady-sleep:2026-09-28:7.2.
  7. Add Copy to Clipboard, then Show Notification with Sleep copied. Open Steady to check in.
  8. Run it once and allow Health access. Then in Steady, tap Fill from Health and Paste.

If Duration shows minutes rather than seconds, divide by 60 instead of 3600. Nothing is saved until you tap Save check-in.
